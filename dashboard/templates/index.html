Help & Guide

Quick reference for InsightAgent features

Quick Start

  1. Go to Settings → add a free Groq API key
  2. Go to New Scan → enter a domain → Launch Scan
  3. Wait ~30 seconds for the AI to complete analysis
  4. View the report in Reports tab

CLI Commands

You can also run InsightAgent from the terminal:

python3 main.py --target example.com

python3 main.py --target site.com --no-pdf

python3 main.py --target site.com --keywords "saas, uptime"

python3 main.py --monitor site.com --interval 3600

Bulk Scan Tips

  • Paste competitor domains to compare SEO scores side-by-side
  • Max 10 domains per batch — scans run in parallel
  • Results appear in Jobs and Reports as they complete
  • Best used with Groq or NIM key for AI-powered insights

What InsightAgent Checks

  • SEO Score — 0-100 composite score (A+ to F)
  • Title & Meta — length, keywords, uniqueness
  • H1/H2 structure — heading hierarchy
  • SSL certificate — validity, expiry days
  • Load time — target under 1500ms
  • Sitemap & robots.txt — crawler accessibility
  • Schema markup — JSON-LD rich snippets
  • Open Graph — social sharing metadata
  • Tech stack — Next.js, React, Cloudflare, etc.
  • Images alt text — accessibility & SEO

AI Providers Setup

  • Offline mode: No keys needed — rule-based analysis always runs
  • Best results: Add NVIDIA NIM key (free credits at signup)
  • Free & fast: Groq gives 14,400 free requests/day
  • Keys are saved to .env in the app folder

Monitor Mode

  • Set a domain + interval to auto-scan on schedule
  • Minimum interval: 5 minutes (300 seconds)
  • All scan results saved to Reports with timestamps
  • Stop any monitor from the Monitor page
